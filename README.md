# Telegram Voice Bot

Интеллектуальный Telegram-бот, который принимает голосовые сообщения, транскрибирует их с помощью Whisper AI и отвечает умными ответами на основе содержания.

## 🎤 Возможности

- Принимает голосовые сообщения от пользователей
- **Транскрибирует речь с помощью Whisper AI**
- **🚀 Автоматическое ускорение с CUDA (если доступно)**
- **Анализирует содержание и генерирует умные ответы**
- Обрабатывает текстовые сообщения
- Отвечает случайными текстовыми заглушками
- Обрабатывает команды `/start`, `/help`, `/menu` и `/status`
- Интерактивное меню с кнопками
- Индикатор "идёт обработка" для всех сообщений
- Логирует информацию о полученных сообщениях

## 🚀 Установка и запуск

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

**Примечание:** 
- При первом запуске Whisper автоматически загрузит модель "base" (~140MB)
- Если у вас есть NVIDIA GPU с CUDA, транскрипция будет автоматически ускорена
- Для CUDA требуется PyTorch с поддержкой CUDA

### 2. Настройка бота

1. Создайте бота через [@BotFather](https://t.me/BotFather) в Telegram
2. Получите токен бота
3. Скопируйте файл `env_example.txt` в `.env`
4. Замените `your_bot_token_here` на ваш токен:

```
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
```

### 3. Запуск

```bash
python LLMawyer/bot.py
```

## 📝 Использование

1. Найдите вашего бота в Telegram
2. Отправьте команду `/start`
3. Используйте интерактивное меню или отправьте голосовое/текстовое сообщение
4. **Для голосовых сообщений:** получите транскрипцию и умный ответ на основе содержания
5. **Для текстовых сообщений:** получите обработанный ответ

## 📋 Команды бота

- `/start` - начать работу с ботом (с интерактивным меню)
- `/help` - показать справку (с кнопками навигации)
- `/menu` - показать меню команд
- `/status` - показать статус системы и CUDA

## 🏗️ Архитектура

Бот построен по модульной архитектуре:

- **commands/** - содержит все команды бота
- **handlers/** - обработчики различных типов сообщений
- **ML/** - модуль машинного обучения:
  - `whisper_transcriber.py` - транскрипция голосовых сообщений
  - `text_processor.py` - анализ и обработка текста
  - `cuda_manager.py` - автоматическое управление CUDA
  - `responses.py` - заглушки для ответов
- **bot.py** - основной файл, который объединяет все модули

Такая структура обеспечивает:
- Легкость поддержки и расширения
- Разделение ответственности
- Возможность независимого тестирования модулей
- Читаемость кода

## 🧠 Технологии

- **Python Telegram Bot** - основной фреймворк для бота
- **OpenAI Whisper** - транскрипция голосовых сообщений
- **PyTorch** - основа для Whisper с поддержкой CUDA
- **CUDA** - ускорение транскрипции на GPU (автоматически)
- **FFmpeg** - обработка аудио файлов
- **Python asyncio** - асинхронная обработка
- **Logging** - подробное логирование всех операций
